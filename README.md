# 🚗 Tesla Website Clone

A fully responsive frontend clone of the Tesla website built using React.js, TailwindCSS, and Framer Motion. This project replicates the core design and smooth transitions of the official Tesla homepage, offering an engaging user experience.

---

## 🛠️ Tech Stack

- **React.js** – for component-based UI
- **TailwindCSS** – for utility-first styling
- **Framer Motion** – for animations
- **@fullpage/react-fullpage** – to mimic Tesla’s scroll-based section transitions
- **GitHub Pages** – for deployment

---


## 🧩 Features

- Smooth full-page scroll like Tesla
- Responsive design (mobile-first)
- Motion-based transitions
- Fixed navbar and minimalistic design

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/AYUSH08SAHARIA/Tesla-clone-master.git

# Navigate into the directory
cd tesla-clone

# Install dependencies
npm install

# Start the development server
npm start
